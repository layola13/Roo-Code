### 2. 意图检测正则表达式

**文件**: `src/core/task/Task.ts` - `detectSubAgentIntent()` 方法

**原实现问题**:

```typescript
// 旧版本：只匹配特定动词 + 子代理名称
const regex = new RegExp(`(?:call|invoke|use).*?${agent}|${agent}.*?(?:subagent|agent)`, "i")
```

**优化后实现**:

```typescript
/**
 * 三层匹配策略（按优先级）
 *
 * 1. 高置信度：明确意图词 + 子代理名称
 *    - "I need|want|will|let's + 子代理"
 *    - "call|invoke|use|run|execute + 子代理"
 *
 * 2. 中置信度：子代理名称 + 上下文关键词
 *    - "子代理 + to|for|will|should|can"
 *
 * 3. 过滤器：排除描述性文本
 *    - "is a|is the|what is|about" → 不触发
 */
const patterns = [
	// 高置信度模式
	new RegExp(`\\b(?:i\\s+(?:need|want|will)|let'?s?)\\s+(?:the\\s+)?${escapedAgent}\\b`, "i"),
	new RegExp(`\\b(?:call|invoke|use|run|execute)(?:ing)?\\s+(?:the\\s+)?${escapedAgent}\\b`, "i"),

	// 中置信度模式
	new RegExp(`\\b${escapedAgent}\\s+(?:to|for|will|should|can)\\b`, "i"),
	new RegExp(`\\b${escapedAgent}\\s+(?:subagent|agent)\\b`, "i"),
]

// 排除描述性文本
const excludePatterns = [
	new RegExp(`\\b(?:is\\s+a|is\\s+the|what\\s+is|about)\\s+${escapedAgent}\\b`, "i"),
	new RegExp(`\\b${escapedAgent}\\s+\\(`, "i"), // 排除括号注释
	new RegExp(`\\b${escapedAgent}\\s+-`, "i"), // 排除破折号说明
]
```

**改进亮点**:

1. **多层次匹配** - 从最明确到较灵活的模式
2. **自然语言支持** - "I need", "I want", "Let's" 等常见表达
3. **动词变体** - "call", "calling", "execute", "executing"
4. **智能过滤** - 排除描述性/文档性文本
5. **大小写不敏感** - 所有模式都使用 `i` 标志

### 3. 消息处理集成

**文件**: `src/core/assistant-message/index.ts` - `presentAssistantMessage()` 方法

**集成位置**: 在 `text` 块处理中

```typescript
case "text":
    // 1. 累积文本内容
    accumulatedMessage += content.text

    // 2. 发送文本到 UI
    await this.say("text", content.text)

    // 3. 检测子代理调用意图
    const detectedAgent = this.detectSubAgentIntent(content.text)
    if (detectedAgent && !subAgentInvokedInThisMessage) {
        subAgentInvokedInThisMessage = true
        const subAgentResult = await this.executeSubAgentByIntent(detectedAgent)

        if (subAgentResult?.success && subAgentResult.output) {
            // 4. 将结果注入到对话中
            await this.say("text", `\n\n# Context Summary (Generated by SubAgents)\n\n`)
            await this.say("text", subAgentResult.output)
        }
    }
    break
```

**关键设计**:

- **实时检测** - 在文本流式输出时立即检测
- **一次性执行** - 使用 `subAgentInvokedInThisMessage` 标志防止重复调用
- **结果集成** - 将子代理输出作为 Context Summary 注入对话
