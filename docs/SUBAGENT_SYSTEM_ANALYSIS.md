## 一、系统概述

### 1.1 子代理模式架构

子代理系统通过 **独立上下文执行** + **精炼输出** 的方式实现智能上下文压缩，目标是节省 83% 的 token 使用量。

**核心原理**:

```
主对话上下文 (17K tokens)
    ↓ 启用子代理压缩
3个子代理顺序分析 (各自使用输入tokens)
    ↓ 返回压缩后的摘要
新的上下文 (2.8K tokens + 摘要)
    ↓
节省: ~83% tokens (根据提示词设计)
```

### 1.2 系统组件

#### 后端核心文件:

1. **`src/shared/subagent-prompts.ts`** (715行)

    - 定义3个子代理的默认系统提示词
    - 导出 `DEFAULT_SUBAGENT_PROMPTS` 常量
    - **Context Analyzer**: 对话流程分析 (目标压缩率 10-15%)
    - **Memory Extractor**: 关键信息提取 (目标压缩率 <20%)
    - **Code Summarizer**: 技术上下文总结 (目标压缩率 <15%)

2. **`src/core/condense/SubAgentExecutor.ts`** (326行)

    - 独立的子代理执行系统
    - 不依赖 Task.startSubtask() 基础设施
    - 直接通过 ApiHandler.createMessage() 调用 AI 模型
    - 支持自定义提示词覆盖
    - 实现3个子代理的顺序执行

3. **`src/core/condense/index.ts`** (540行)

    - `summarizeConversation()` 函数集成子代理压缩
    - 条件启用逻辑：当 `subAgentConfig` 参数存在且有效时
    - 回退机制：子代理压缩失败时使用标准LLM压缩

4. **`src/core/task/Task.ts`** (关键集成点)
    - `condenseTaskContext()` 方法触发上下文压缩 (行1153-1246)
    - 从 ContextProxy 读取用户配置
    - 构造 SubAgentConfig 并传递给 summarizeConversation
    - 处理压缩结果并更新UI

#### 前端核心文件:

1. **`webview-ui/src/components/chat/TaskHeader.tsx`**

    - 显示压缩比率和子代理token使用统计
    - 表格展示每个子代理的输入/输出tokens和成本

2. **`webview-ui/src/components/chat/ContextCondenseRow.tsx`**

    - 展示上下文压缩结果
    - 包含子代理详情的可折叠区域
    - 显示压缩前后的token对比

3. **`src/shared/WebviewMessage.ts`**
    - 定义 `ContextCondense` 接口
    - 包含 `subAgentTokenUsage` 数组字段

#### 配置管理:

**`src/core/config/ContextProxy.ts`** - 管理全局配置状态:

- `useSubAgentCompression`: 总开关
- `useContextAnalyzer`: 启用上下文分析器
- `useMemoryExtractor`: 启用记忆提取器
- `useCodeSummarizer`: 启用代码总结器

- `memoryExtractorPrompt`: 自定义提取器提示词

### 4.2 顺序执行性能问题 ⚠️

**当前实现**:

```typescript
// SubAgentExecutor.ts:89-173 - 串行执行
const analyzerResult = await executeContextAnalyzer(...)  // 等待完成
const extractorResult = await executeMemoryExtractor(...) // 再等待完成
const summarizerResult = await executeCodeSummarizer(...) // 最后等待完成
```

**性能影响**:

- 假设每个子代理耗时2秒，总耗时 = 6秒
- 3个子代理之间没有依赖关系，可以并行

**优化方案**:

```typescript
// 并行执行，总耗时 = max(2秒) = 2秒
const [analyzerResult, extractorResult, summarizerResult] = await Promise.all([
    executeContextAnalyzer(...),
    executeMemoryExtractor(...),
    executeCodeSummarizer(...)
])
```

**预期收益**:

- 压缩耗时减少 ~67% (从6秒到2秒)
- 用户体验显著提升

### 4.3 默认禁用 ⚠️

**当前状态**:

- `useSubAgentCompression` 默认值为 `undefined`
- 用户必须手动在设置中启用

**影响**:

- 大多数用户不知道此功能存在
- 无法体验83% token节省的价值

**建议**:

- 考虑默认启用（或在首次使用时提示）
- 添加实验性功能标识和用户教育
